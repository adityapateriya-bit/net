Understanding the results

Open

The TCP handshake completed (SYN → SYN/ACK → ACK). A program is listening and accepting connections on this port.

Closed

The host replied with a reset (RST). It is reachable, but nothing is listening on this port.

No response

Nothing came back before the timeout. Usually a firewall is silently dropping packets, or the host is offline.

Why port management matters

Every open port is a door into a system. Services you don't need — an old database, remote desktop, a forgotten dev server — should be stopped or firewalled. Scan your own machines regularly and close what you don't recognise.

Only scan systems you own or are authorised to test. scanme.nmap.org is a host whose owners explicitly allow light test scans.
